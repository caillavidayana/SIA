# R02: Cotizaciones de proveedores distintos

Rama prevista: `regla-02-cotizaciones`.

Por encima del umbral exige tres cotizaciones válidas de proveedores distintos; permite completar borradores sin perder archivos.

Archivos de revisión: compras/reglas_cotizaciones.py; compras/models.py; soporte/views.py; mantenimiento/views.py; frontend/src/components/CotizacionesRequerimiento.vue; frontend/src/components/CotizacionesExpediente.vue.

Configuración: `SIA_UMBRAL_COTIZACIONES; SIA_COTIZACIONES_MINIMAS; SIA_PROVEEDORES_DISTINTOS`, valor inicial 500; 3; True.

Validación esperada: Con 500 no se exige el mínimo adicional; con 700, una o dos cotizaciones bloquean y tres de proveedores distintos permiten continuar. Repetir nombre con distintas mayúsculas o el mismo NIT no cuenta como proveedor adicional.

Reversión de configuración: Restaurar 500, 3 y True; reiniciar. Conservar las cotizaciones y sus archivos.
